# Test Course (1 hour)

## Course Description

Testing pipelines manually or without automated checks does not scale for curriculum delivery.

This course teaches how to verify and test pipeline workflows through a concise hands-on module.

## Learning Objectives

- Successfully run and verify a test course pipeline
- Execute a sample test workflow and validate pipeline integrity

## Who Should Attend

Anyone

## Prerequisites

- None

## Hands-On Activities

- Lab: Running the Test Workflow

## Course Outline

**Module 1: Test Workflow**

- Pipeline Overview
- Verification
- Lab: Running the Test Workflow
